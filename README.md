# DevTwin

DevTwin is a static portfolio site built using **Next.js** (static export), showcasing the work and profile of Parsa and Parham — one working with frontend and the other with backend (NestJS).

Live Demo: [devtwin.ir](https://devtwin.ir/)  

Set `SITE_URL` to the production origin at build time to use it across canonical URLs, social previews, and the sitemap. It defaults to `https://devtw.in`.

## Tech Stack

| Layer        | Technology                     |
|---------------|-------------------------------|
| Frontend      | Next.js (App Router, `output: "export"`) |
| Bundler / Dev | Next.js                        |
| Styling       | CSS Modules |
| Hosting        | Netlify |
---
## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/devtwin.git
cd devtwin
npm install
npm run dev
```
